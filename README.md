# Poliklinik Udinus Website

**Poliklinik Udinus Website** is a web-based clinic management system developed using **PHP** and **MySQL**.

The application was developed as part of a **Web Developer certification project by BNSP (Badan Nasional Sertifikasi Profesi)** and is designed to support clinic operations involving administrators, patients, and doctors through a centralized web-based system.

## 🏥 About the Project

Poliklinik Udinus Website provides an integrated system for managing clinical data and operational workflows.

The platform separates functionality based on three main user roles:

* Admin
* Patient
* Doctor

Each role has access to specific features based on its responsibilities within the clinic workflow.

## 👥 User Roles

### Admin

The administrator manages the main reference data required by the clinic system.

Admin capabilities include:

* Admin authentication
* Doctor management
* Patient management
* Clinic department management
* Medicine management

### Patient

Patients can access the platform to manage their clinic registration process.

Patient capabilities include:

* Patient authentication
* Patient registration
* Registration to a clinic department
* Access to relevant registration information

### Doctor

Doctors can manage schedules, examinations, treatment information, and patient records.

Doctor capabilities include:

* Doctor authentication
* Doctor profile updates
* Examination schedule management
* Patient examination
* Examination cost calculation
* Medication notes
* Patient history access

## 🔐 Authentication & Access

The application implements separate authentication flows for:

* Admin
* Patient
* Doctor

Each user role is provided with access to functionality relevant to its responsibilities within the clinic system.

## 🩺 Patient Registration

Patients can register through the application and select the clinic department they want to visit.

The registration process is integrated with patient and clinic data to maintain a structured workflow before examination.

## 👨‍⚕️ Doctor Management

Doctors can manage their personal information and examination schedules through the system.

The doctor workflow also includes patient examination, examination cost calculation, medication notes, and access to patient history.

## 💊 Medicine Management

Medicine data is maintained within the system and can be used as part of the examination and treatment workflow.

Doctors can provide medication-related notes based on the patient's examination results.

## 📋 Patient History

The application maintains patient examination records, allowing doctors to review previous patient history.

This provides structured access to historical examination information and supports continuity within the clinical workflow.

This project was developed to:
